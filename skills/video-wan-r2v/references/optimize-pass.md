# 出图提示词优化（Wan 写法）

你拿到的是设定集里已经写好的英文出图提示词（`image.prompt` 主视角图、`image.sheet` 设定图/参考板）。
按通义万相（Wan）文生图的提示词习惯重写，**内容事实不变，只改写法**。

## Wan 的写法

1. **公式：主体 + 场景 + 风格 + 镜头 + 氛围光影。** 主体写在最前，细节越具体越好（年龄、体态、五官特征、服装的材质 / 颜色 / 磨损、配饰）。
2. **用完整的描述性句子，** 不堆关键词；一个画面里的空间关系写清楚（谁在左 / 右、前景 / 背景）。
3. **光影与氛围单独成句：** 光源方向、软硬、色温、时间段。
4. **镜头与景别明确：** 近景 / 半身 / 全身 / 平视 / 俯拍，必要时写镜头焦段。
5. Wan 支持独立的反向提示词字段，所以**不需要**在正向提示词里写 "no X / without X"；正向里只写要的东西。反向字段不归你管，不要输出。
6. 主视角图 `prompt`：约 80–150 词；设定图 `sheet`：保留全部版面指令，允许到 250 词。

## 不许动的（改了会被质量门拒收）

- **不许出现任何角色名、别名、人名、作品名**；描述这个人 / 物，不要叫名字。
- **全英文**，不许夹中文。
- **版面指令原样保留**：16:9 比例、三个分区的位置与比例、正视 / 侧视 / 背视并排、细节条、白底、分区光照等——可以润色措辞，但每一条结构要求必须还在。
- 道具的尺度短语（如 "handheld scale"）和 white background 原样保留；道具不画手。
- 场景是无人空景，不要加人。
- **不要写画风**（photorealistic / anime / 3d render 等）：画风由出图阶段统一加。
- 不增删设定：不改年龄、身份、服装、颜色、道具、空间布局；不编造新物件。

## 输出

只输出 JSON，不要解释：`{"prompt": "...", "sheet": "..."}`。输入里没有的字段不要输出。
