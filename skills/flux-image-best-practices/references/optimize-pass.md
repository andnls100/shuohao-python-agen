# 出图提示词优化（FLUX 最佳实践）

你拿到的是设定集里已经写好的英文出图提示词（`image.prompt` 主视角图、`image.sheet` 设定图/参考板）。
按 FLUX 的写法把它们重写得更好，**内容事实不变，只改写法**。

## 要做的

1. **只用正向描述。** FLUX 不支持负面提示词：把 "no X / without X" 改成要的东西（"bare head" 而不是 "no hat"）。负面提示词字段不归你管，不要输出它。
2. **主体放最前面。** 词序靠前的元素权重更高：谁/什么 → 外观细节 → 姿态 → 环境 → 光照 → 镜头。
3. **自然语言连贯成句，** 不要关键词堆砌（不要 "8k, masterpiece, ultra detailed"）。
4. **写清光照。** 光源方向、质感、色温；光照对质量影响最大。
5. **具体。** 材质、磨损、颜色（可用 "deep navy #1F2A44" 的写法）、年龄、体态、布料垂感，把含糊形容词换成可见细节。
6. 主视角图 `prompt`：约 60–120 词。设定图 `sheet`：保留原有版面指令，允许到 250 词。

## 不许动的（改了会被质量门拒收）

- **不许出现任何角色名、别名、人名、作品名**；描述这个人/物，不要叫名字。
- **全英文**，不许夹中文。
- **版面指令原样保留**：16:9 比例、三个分区的位置与比例、正视/侧视/背视并排、细节条、白底、分区光照等——可以润色措辞，但每一条结构要求必须还在。
- **道具的尺度短语**（如 "handheld scale"）和 **white background** 原样保留；道具不画手。
- 场景是**无人空景**，不要加人。
- **不要写画风**（photorealistic / anime / 3d render 等）：画风由出图阶段统一加，写进来会冲突。
- 不增删设定：不改年龄、身份、服装、颜色、道具、空间布局；不编造原提示词里没有的新物件。

## 输出

只输出 JSON，不要解释：`{"prompt": "...", "sheet": "..."}`。输入里没有的字段不要输出。
